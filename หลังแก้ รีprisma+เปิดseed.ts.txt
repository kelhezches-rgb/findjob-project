จากนั้นบันทึกไฟล์ แล้วรันใหม่ตามลำดับ:

cd /d "D:\FindJob Project\backend"

npx prisma format
npx prisma generate
npx prisma db push
npx ts-node prisma/seed.ts
npm run dev
